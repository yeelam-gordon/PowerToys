## 6. Quirks discovered (now documented as Gotchas)

1. **UWP/packaged apps expose no window under their own process.** `CalculatorApp`
   reports `Window: (none)`; the real window (HWND `4065634`) is owned by
   `ApplicationFrameHost`. Target it with `-w <HWND>` (from `list-windows`), not
   `-a Calculator`. `-a` alone found 0 elements.
2. **`automationId` works as a selector** (`num1Button`) in addition to the
   hash-suffixed semantic slug (`btn-num1button-fec5`), and is far more stable
   across restarts — prefer it when present.
3. **`get-value` on the display returns `"Display is N"`**, not a bare `"N"` —
   assert with `contains`, not `equals`.
4. **Transient `element_not_found`** happens when calls fire while the app is
   mid-animation / regaining foreground. `signoff.py` retries transient failures
   (default 2×, 0.4 s backoff); a small `--step-pause` also helps.
5. **Emoji in reports crash a cp1252 console.** The runner reconfigures
   stdout/stderr to UTF-8; report files are always written UTF-8.
