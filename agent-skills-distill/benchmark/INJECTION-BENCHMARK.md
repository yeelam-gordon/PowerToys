# Injection Benchmark — "Fake a problem in PowerToys, prove the sign-off catches it"

This benchmark measures whether a distilled **sign-off skill** actually catches regressions.
It does **not** trust the checklist text — it **plants real faults in real PowerToys source,
rebuilds the real module, drives the real UI with winappcli, and records whether the declarative
check flips to FAIL**.

## Why this exists

A sign-off checklist that *looks* thorough is worthless if its checks don't fire when the feature
breaks. The only honest proof is **fault injection**: deliberately break the behavior each check
claims to guard, and confirm the check catches it — with a clean-build control proving it does
**not** false-alarm when nothing is broken.

## Method (per module)

```
0. Clean baseline:   build the module clean → run the full sign-off → assert 0 failures  (false-positive control)
1. For each fault i in 1..N:
     a. patch ONE source line in the real module (a surgical find/replace that breaks one behavior)
     b. rebuild the real project with MSBuild (Release/x64)
     c. relaunch the real app
     d. run the REAL winappcli check that is supposed to guard that behavior
     e. record CAUGHT if the check flips to FAIL vs. the clean baseline; screenshot the UI
     f. revert the source line
2. Rebuild clean; assert baseline is green again.
CATCH RATE = (# faults caught) / N.     FALSE-POSITIVE RATE = failures on the clean build.
```

**Catch criterion** = the targeted checklist item flips to FAIL vs. clean baseline. (The P0 release
*gate* is stricter — it only trips on P0 items — so a caught P1/P2 fault can leave `gate=PASS`
while still being detected. Detection is the bar; see `results/ACCEPTANCE-10x10.md`.)

## Harness

Real, re-runnable PowerShell + Python + winappcli. The committed runners live in each
sign-off skill's `scripts/` folder; the per-fault artifacts (`json`/`md`/`png`) are
**generated when the campaign runs and are not committed** in this PR:

| Module | Fault definitions + runner (committed) | Per-fault artifacts (generated, not committed) |
|--------|----------------------------------------|------------------------------------------------|
| AdvancedPaste | `distilled-skills/powertoys-advancedpaste-signoff/scripts/injections.ps1` (10 surgical source patches) + `run_injections_uia.ps1` (and `run_injections_clip.ps1` clipboard variant) | `inj-I1..I10.{json,md}` + `screenshots/inj-I*/` |
| PowerRename | `distilled-skills/powertoys-powerrename-signoff/scripts/run-signoff.py` driven per injected fault | `report_INJ1..10.{json,md}` |
| PowerAccent | `distilled-skills/powertoys-poweraccent-signoff/scripts/run_signoff.py` (glyph/lifecycle executors) | `regression-R*.results.json` |

### Example planted faults (AdvancedPaste — each breaks exactly one behavior)

| ID | File patched | Fault | Guarded by |
|----|--------------|-------|-----------|
| I1 | `Helpers/TransformHelpers.cs` | plain-text output gets `_INJ` appended | CHK-01 |
| I2 | `Helpers/MarkdownHelper.cs` | markdown transform returns raw HTML | CHK-02 |
| I3 | `Helpers/JsonHelper.cs` | every CSV cell becomes constant `"X"` | CHK-03 |
| I5 | `Helpers/JsonHelper.cs` | `IsJson` always false (passthrough broken) | CHK-05 |
| I6 | `Helpers/JsonHelper.cs` | plain-text JSON fallback drops all lines | CHK-06 |
| I7 | `ViewModels/OptionsViewModel.cs` | AI-gating guard returns `true` (AI box enabled when it should be gated) | CHK-07 |
| I8 | `Helpers/ClipboardItemHelper.cs` | clipboard preview hard-coded to `__CORRUPT__` | CHK-08 |
| I9 | `Models/PasteFormats.cs` | Markdown flagged non-core (drops from action list) | CHK-09 |
| I10 | `Helpers/MarkdownHelper.cs` | markdown conversion strips all `*` (bold lost) | CHK-10 |

Each is a real compile-and-run change to shipping source, reverted after measurement.

## Honest limitations

- **Synthetic input requires an unlocked, input-owning session.** On a locked/disconnected RDP
  desktop, `SendInput` returns `ACCESS_DENIED` and `ForegroundWindow=0`. Checks that need a real
  keystroke (e.g. PowerAccent overlay summon, AdvancedPaste's final Ctrl+V paste) can't run there;
  the harness downshifts to UIA reads / clipboard-output / glyph-data verification and this is
  disclosed per module, not hidden.
- **This benchmark proves the sign-off catches breakage; it does not prove the checklist is
  exhaustive.** N faults chosen per checklist item = N items proven live. Widening N widens coverage.

## Reproduce

```powershell
# AdvancedPaste (needs winappcli + a buildable PowerToys clone at <powertoys-root>, unlocked session for the paste variant)
pwsh distilled-skills/powertoys-advancedpaste-signoff/scripts/run_injections_uia.ps1
# PowerRename (drive the committed sign-off runner per injected fault)
python distilled-skills/powertoys-powerrename-signoff/scripts/run-signoff.py --powertoys-root <powertoys-root> --report-json out.json --report-md out.md
```
